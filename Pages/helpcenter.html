ENGINE DATABASE / 001

About RPG Maker MV

SSIA: Vanguard Chronicles currently uses RPG Maker MV as its unified development platform for Windows and Android. The current game is developed around the MV engine rather than treating MV as an experimental or future platform.

  • RPG Maker MV is the current engine used by SSIA: Vanguard Chronicles.
  • Windows and Android builds are based on the MV development foundation.
  • MV uses JavaScript-based systems and a different save architecture from VX Ace.
  • Performance can vary depending on hardware, operating system, plugins, graphics workload, and background applications.
  • Always check the official release notes for version-specific engine or compatibility changes.
LEGACY ENGINE / 002

RPG Maker VX Ace Legacy Builds

Earlier Windows releases of SSIA: Vanguard Chronicles used RPG Maker VX Ace. These builds are now considered legacy versions following the transition to RPG Maker MV.

  • Current SSIA: Vanguard Chronicles development uses RPG Maker MV.
  • VX Ace builds may have different runtime, file structure, plugin/script, and save requirements.
  • VX Ace save data should not be assumed to work with current MV builds.
  • Keep legacy installations and their save data backed up if you still need them.
  • Do not delete an old installation until you have confirmed that any required legacy saves have been safely backed up.
TSBC PLATFORM / 003

TSBCPlay

TSBCPlay is the Windows launcher and distribution platform for supported TSBC Games titles. It provides the supported desktop route for accessing SSIA: Vanguard Chronicles on Windows.

  • Install TSBCPlay using the official TSBC Games distribution source.
  • Launch TSBCPlay and locate SSIA: Vanguard Chronicles.
  • Allow TSBCPlay to download or manage the required game files when applicable.
  • Do not manually remove files managed by the launcher unless TSBC support instructs you to do so.
  • If installation fails, restart TSBCPlay and verify your storage space and network connection.
  • For launcher-specific issues, include your TSBCPlay version when submitting a bug report.
ACCOUNT SERVICES / 004

SSIAVerse Account

SSIAVerse is TSBC's centralized account and identity ecosystem for supported TSBC services and games. It is designed to provide a shared identity experience across supported parts of the TSBC ecosystem.

  • Use your SSIAVerse account when a supported TSBC service requests authentication.
  • Supported TSBC services can use the centralized SSIAVerse identity system.
  • TSBCPlay and supported TSBC Games features may use SSIAVerse authentication where implemented.
  • Never share your password, authentication code, or account credentials with another person.
  • If you cannot sign in, verify your credentials and use the official account recovery process.
  • Account-related reports should include useful error information without exposing private credentials or authentication codes.
SAVE SUPPORT / 005

Save Data Recovery and Backup

Your save data contains your game progress. Always create a backup before updating, reinstalling, moving the game, or performing major troubleshooting.

  • Back up your current working save data before making major changes to the installation.
  • Save locations and file formats can differ between VX Ace legacy builds and current RPG Maker MV builds.
  • Do not assume that a VX Ace save can be opened by an MV version.
  • Store backups separately from the active game installation.
  • If a save appears corrupted, preserve the original before attempting recovery.
  • Never overwrite your only known-good backup with a potentially damaged save.
UPDATE SUPPORT / 006

Moving Save Data to a Newer Version

Save migration depends on the specific SSIA: Vanguard Chronicles release. Always check the release notes before copying save data into a newer version.

  • Create a complete backup of your current save data first.
  • Install the new official game version without immediately deleting the previous installation.
  • Do not copy VX Ace save data into an MV build unless TSBC explicitly confirms compatibility.
  • For MV-to-MV updates, follow the save migration instructions provided for that release.
  • Launch the new version and verify that your progress loads correctly.
  • Keep the previous version and backup until the migration has been confirmed successful.
PERFORMANCE SUPPORT / 007

Low Specification Windows PC

SSIA: Vanguard Chronicles is a 2D RPG built around RPG Maker MV, but older or lower-spec Windows systems may still experience loading delays, stuttering, or other performance issues.

  • Close unnecessary browsers, launchers, recording software, and editing applications.
  • Connect a laptop to AC power if battery mode limits system performance.
  • Make sure the game is properly installed or extracted instead of running directly from a compressed archive.
  • Use SSD storage when possible for improved loading performance.
  • Restart Windows if performance becomes unusually poor after extended use.
  • Keep sufficient free storage available for Windows and game operations.
  • If the issue persists, include your PC specifications in the bug report.
MOBILE SUPPORT / 008

Android Installation and Support

The Android edition of SSIA: Vanguard Chronicles uses the RPG Maker MV-based development platform and is distributed through official TSBC Games release channels.

  • Download the Android build only from an official TSBC Games distribution source.
  • Make sure your device has sufficient free storage before installation or updates.
  • Allow required game data to finish downloading or installing before launching into normal play.
  • Avoid interrupting an active update or data installation.
  • Restart the application if it becomes temporarily unstable.
  • If the issue continues, include your Android version, device model, game version, and reproduction steps in the report.
FIELD REPORT / 009

Bug Reports

If you encounter a crash, glitch, softlock, typo, missing dialogue, broken event, map issue, gameplay problem, launcher issue, or unexpected behavior, provide enough information for TSBC to reproduce and investigate the problem.

  • Include the exact SSIA: Vanguard Chronicles version or build number.
  • State whether the issue occurred on Windows or Android.
  • For Windows issues, mention whether the game was launched through TSBCPlay.
  • For account issues, identify the affected SSIAVerse feature without sharing passwords or authentication codes.
  • Explain where the issue happened: map, chapter, quest, menu, scene, account screen, or combat encounter.
  • Describe what you were doing immediately before the problem appeared.
  • Attach screenshots or video when possible.
  • State whether the problem can be reproduced.
  • Preserve your save backup until the issue has been investigated.
