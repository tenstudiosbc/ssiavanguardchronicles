LAN Multiplayer Features — Version 1.1.2

LAN Multiplayer is in development for SSIA: Vanguard Chronicles version 1.1.2. The current LAN Core source is designed to connect Windows and Android players over a local network, using the Windows NW.js TCP transport and the Android LAN bridge.

  • Host or join: create a named room or connect using the host’s IP address and port.
  • Lobby readiness: players can set their ready status; the host can send the start request when everyone listed is ready.
  • Player communication: the core includes chat-message sending and relays game packets between connected clients.
  • Connection status: lobby status, player list, connection and disconnect states are surfaced in the LAN menu.

This feature is still being developed and needs runtime testing across the Windows and Android bridges and multiple devices. PING/PONG packet handling is present as protocol groundwork; automatic heartbeat timeouts and reconnection are not claimed as available.
